Pink? Materials will appear pink or nothing will be visible if you are using High Definition 3D render pipeline (HDRP) or the Built-In render pipeline. To fix this. Simply open up the "Legacy" folder and import the "HDRP" package if you are using High Definition or the "Built-In" package if using Built-In.

--------------------------------------------------------

Pick your space station and assign a different color from the materials folder. You can also create your own custom colors through the Colorize materials. 

The "Examples" prefabs are the space stations with a single combined mesh. The "Modular Examples" have all the different modules separated so you can make your own changes.

Create a new space station either by modifying an existing modular example or by creating a new one from scratch through the provided modules.

--------------------------------------------------------

For Built-In Render Pipeline Users Only
You will need to install Unity's "Shader Graph" package to use the Colorize materials. Otherwise those Colorize materials will also have missing shaders/pink color. To install shader graph. Go to the "Package Manager" window and find the Shader Graph Package inside "Pacakges: Unity Registry".

Bonus Content
Alien space stations, arcade space stations, debris, crates and space objects are some of our older assets which we have included in this pack as an extra in case someone could make use of them. They are added as a little additional bonus. The core of this pack is the space stations four sets (bridge, cylinderical, hangars and storage).

Please note that the Alien space stations are compatible with the following alien spaceships within the Ultimate Spaceships Creator:
-Proton Legacy
-Astro Eagle
-Craizan Star

Animation Controllers
Animations and animation controllers were added for the warp gates set we included in V3.3. If you use the warp effects, you might notice that there are 2 animation controllers for each clip. The second controller is only created to add a slight variation in the warp effect animation speed by changing the play speed.
